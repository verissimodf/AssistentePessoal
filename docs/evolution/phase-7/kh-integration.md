# Integração — Knowledge Hub (Fase 7, §12.2)

- Eventos de novos conhecimentos e atualizações entram como fonte `kh` na whitelist;
  regras contextuais podem recomendar ações (ex.: transformar documento novo em nota).
- Recomendações fundamentadas preservam **referências e proveniência**: o payload
  carrega ids de biblioteca/documento; a justificativa cita o evento real.
- Conteúdo de documentos é DADO NÃO CONFIÁVEL — nunca instrução de sistema (invariantes
  das Fases 2/5 mantidas).

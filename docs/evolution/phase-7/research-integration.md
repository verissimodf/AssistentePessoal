# Integração — Deep Research (Fase 7, §12.3)

- Acompanhamento: eventos do ciclo de pesquisa (fonte `research`) — conclusão,
  falha — alimentam regras (o fluxo canônico da demo de aceite usa
  `research_completed`).
- Etapas posteriores: a oportunidade recomenda o próximo passo configurado pelo
  operador (ex.: armazenar no Hub, revisar fontes); ao aceitar, o workflow real inicia
  com as políticas normais.
- Nenhuma fabricação de resultados: a justificativa cita o evento observado; as
  evidências referenciam o projeto de pesquisa; citações continuam verificáveis na
  interface da Fase 4.
